# SUDOGRID – Interactive Sudoku Solver

## Overview

SUDOGRID is a Java-based interactive Sudoku application that allows users to solve a 9×9 Sudoku puzzle through a graphical user interface. Users can enter numbers, validate their moves, view the solution, and manage the puzzle using interactive controls.

## Features

- Interactive 9×9 Sudoku board
- Number selection using buttons from 1–9
- Move validation
- Incorrect move highlighting
- Solution and Hide Solution functionality
- Reset game with confirmation
- Exit application with confirmation
- User-friendly graphical interface

## Sudoku Rules

- Each row must contain digits 1–9 without repetition.
- Each column must contain digits 1–9 without repetition.
- Each 3×3 sub-grid must contain digits 1–9 without repetition.

## Technologies Used

- Java
- Java Swing
- AWT
- NetBeans IDE

## Application Workflow

1. Select a number from the available buttons (1–9).
2. Choose an empty cell on the Sudoku board.
3. Enter the selected number into the cell.
4. Use **Check Moves** to validate the entered values.
5. Incorrect moves are highlighted for easier identification.
6. Use **Solution** to view the solution and **Hide Solution** to return to the puzzle.
7. Use **Reset** to restart the puzzle when required.
